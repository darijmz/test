Este proyecto fue desarrollado como parte del Sprint 7 Herramientas de Desarrollo de Software.
El objetivo es construir una aplicación web interactiva utilizando Streamlit, Pandas y Plotly Express, que permita visualizar y explorar un conjunto de datos de anuncios de venta de vehículos en Estados Unidos.

La aplicación permite al usuario:

Visualizar el dataset original de vehículos.

Generar gráficos interactivos (histogramas y diagramas de dispersión) para analizar las relaciones entre variables como el precio y el odómetro.
